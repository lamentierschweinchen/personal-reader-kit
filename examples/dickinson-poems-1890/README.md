# Poems — Emily Dickinson, First Series

[Read Poems](https://newreading.app/dickinson/) · [Source and reuse terms](docs/SOURCE-RIGHTS.md)

The 1890 Roberts Brothers volume, edited by Mabel Loomis Todd and T. W. Higginson. The reader opens at the Prelude. Contents includes the title and imprint, Higginson’s preface, and all 115 numbered poems in the four books.

Run `npm test` and `npm run build` to verify and build the exact public edition. The application code is MIT. The adapted Wikisource transcription is available under CC BY-SA 4.0, with credits in the reader and the source record.
