# Real-book trial feedback · Walden

This project now contains a usable complete reader, not a plan. It is an independent local adaptation of published kit v0.4.0 (`4c386ed521dc16f1bd08c96c3eafbdf765b4f4e7`). The reusable kit and sibling readers were not edited. No remote or deployment was created. This agent trial is **not** a completed human newcomer pilot.

## What worked unchanged

The plain-JavaScript shell, IndexedDB storage, text selection and UTF-16 anchors, local note persistence, late-range context placement, focus recall/exit, appearance settings, permission boundaries, exact literal word index, saved-passage comparison, and backup/bundle transactions supplied real functionality immediately. Large source paragraphs did not require artificial splitting. The content-versioned service worker cached the actual books and companion after the build was explicitly adapted.

The source-first guide was useful. The bounded EPUB preparer refused an unsupported manifest before emitting a misleading partial edition. The original sample hash/build rules and conservative publication scanner made the authorization boundary visible rather than silently accepting a book dropped into `site/`.

## Verification evidence

Run `npm test`, `npm run build`, `TEST_PORT=4293 npm run test:walden-browser`, then stage reviewed files and run `npm run audit:public`. Installed Playwright 1.62.1 was reused with Chromium 148 (cache 1223) and WebKit (cache 2359); browser paths are configured by environment, not committed into source.

The final Node suite has 30 passing tests: the 27 inherited tests plus real-edition structure/image-contract/bundle tests. Both browser engines passed the following actual-book checks:

- **Independent fidelity:** all 570 source text leaves agree with browser-parsed source logical text; all 19 chapter/essay headings agree; all 280 italic spans agree. All 22 rendered sections (including front matter and attached source-licence appendices) agree with the prepared contract. Counts alone were not used as fidelity proof.
- **Device layouts:** 390×844 phone, 844×390 phone landscape, 820×1180 tablet and 1180×820 tablet landscape. Fixed accounts scroll locally; indented verse retains NBSPs and explicit breaks; no document overflow. Screenshots were settled after font/transition completion and transient save messages.
- **Annotation:** actual late words in Economy's longest paragraph at 36 px are within the passage dialog's usable viewport, below its sticky title. Note save/reload and all four viewport return checks pass. A synthetic IndexedDB write failure retains the actual unsaved note, which saves after the fault is removed.
- **Focus:** saved preference survives reload; deliberate keyboard recall, hidden controls during selection, save in focus, visible title/continuation and Escape exit work with actual content. This is browser DOM/keyboard evidence, not native finger-selection evidence.
- **Companion:** later readings initially stay hidden. Explicit permissions reveal the expected readings, source context preserves the main reading place exactly, and 36 px applies to the substantial reading. The literal word index opens exact occurrence offsets and retains its query on return.
- **Images:** both original JPEG hashes verified; map decodes to 731×412 and enlarges. The source contents can move between the two distinct works.
- **Backup/restore:** a downloaded private bundle contains both exact works, both image payloads and five test annotations. A fresh browser restores it; reloading and restoring again retains five notes, and permissions are not widened.
- **Cold offline:** stop the test's origin, prove a raw network request fails, close the original page, open a new page in the same browser profile, reload, and read both full works, the survey and the companion with saved notes. Each engine passes. This is a new page/reload in a retained browser profile, not an OS restart or an evicted-storage claim.
- **Network:** no unexpected external requests and no browser page errors during the tested paths. External citations and the source EPUB intentionally require a connection.

Private evidence: `.reader/reports/browser/receipt.json`, settled engine/viewport screenshots, actual exported test bundles, `.reader/reports/fidelity.json`, `.reader/reports/raw-inventory.json`, `.reader/reports/node-tests.log`, and `.reader/reports/walden-publication-review.json`. Raw diagnostics, source downloads and test notes are ignored. The project audit inspects complete locally reachable history, not just HEAD; it reports its exact revision, refs, index/working byte hashes and limitations.

## What remains before public use

The user must judge the reader and the companion. No human learning claim is established by word count or automated completion. Physical iOS, e-ink, native touch selection, screen-reader use, actual origin/device migration by a newcomer and print-exemplar proofreading are pending. The map's alt description does not transcribe every sounding. No current walking route or access claim is made.

A publication destination/audience approval, final distribution/trademark review and applicable jurisdiction check are still required. The catalogue's US public-domain statement is not worldwide clearance. No push/deployment occurred. The kit's fictional samples remain original and unchanged upstream.

A source-edition EPUB is provided, clearly labelled. A future kit EPUB export would need illustrated multi-work navigation, complete source terms, verse/indentation, faithful accounts, emphasis and self-contained assets. Notes do not synchronize to an e-reader.
