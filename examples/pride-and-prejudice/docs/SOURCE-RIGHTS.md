# Source, edition and rights receipt

Inspected and accessed 16 October 2026. This is a local example, not a deployed service. The intended future audience is public; no destination or publication approval has been chosen. No remote is attached.

## Actual edition

[Project Gutenberg 1342](https://www.gutenberg.org/ebooks/1342) supplies Jane Austen’s *Pride and Prejudice* in English, with George Saintsbury’s preface and Hugh Thomson’s illustrations. The actual title page names George Allen, London, 156 Charing Cross Road; illustration notices state copyright 1894 by George Allen. The peacock binding and title art are included. This is the 1894 illustrated edition as represented by Gutenberg’s digital transcription, not the 1813 first edition and not a text-only abridgment.

The catalogue and source header say updated 29 September 2026. HTML metadata gives an Ebookmaker modification date of 1 October 2026. Gutenberg credits Chuck Greif and the Online Distributed Proofreading Team at pgdp.net, from images available at the Internet Archive. The supplied files do not identify a specific Internet Archive scan URL; none has been invented. The digital edition, not an independently collated physical copy, is the fidelity baseline.

## Exact proposed assets

`edition/inventory.json` inventories the prepared library and 164 unchanged image files. Its own SHA-256 is pinned in `publication.json`. The build verifies every asset’s exact bytes and accepts only those paths. The deployed candidate consists of the 11 explicitly listed application files, the 165 inventoried edition assets and the generated service worker: 177 files. It contains no raw archive, private inspection, screenshot, note, backup or sibling-reader file. The original kit samples remain in the repository for regression checks and are excluded from this example’s normal build.

The upstream `audit:public` deliberately still rejects binary assets. `audit:example` runs that complete-history audit and adds a separate exact-hash review for only the 164 source images, including every locally reachable historical version. All other inventory, path, credential, metadata, staging, shallow-history and hidden-history findings remain fatal. This adaptation is local to this reader; this project did not write to the upstream kit.

## E-reader link and future export

Use [the source-edition EPUB download options](https://www.gutenberg.org/ebooks/1342) and select EPUB3 with images. This is a Gutenberg download, not a kit-generated EPUB. Web notes do not synchronize with an e-reader.

A future kit export would need an OPF manifest/spine, navigation hierarchy, source licenses, all 164 image assets, cover semantics, illustrated initials with accessible selectable letters, italics/small capitals, the two source tables, page anchors, internal links, letters and explicit line breaks. It would also need an explicit note-export format and tested e-reader rendering. None is claimed here.
