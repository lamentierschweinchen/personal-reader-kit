# The Book of Tea

Owner-approved public edition at [newreading.app/book-of-tea/](https://newreading.app/book-of-tea/). The complete reading experience and its reviewed source/licensing scope are described in [SOURCE-RIGHTS.md](docs/SOURCE-RIGHTS.md).

    npm test
    npm run build
    npm run dev

The build admits only the explicit runtime and exact edition files pinned in edition-lock.json. It includes no private notes, source archives or preparation evidence. Browser records stay local; export a private reading bundle before changing origins. Read the three-edition release record in the upstream docs/STATUS.md for verification scope and remaining physical-device limits.

Prepared from the independent source checkpoint 64cfa0f867abc2d5597563e3837732e03934caaa. Publication packaging preserves every source byte. Make tea includes sourced modern methods, an adjustable timer and an optional current-tab chime. The chime cannot wake a sleeping device; the timer retains its deadline when reopened.

The independent project’s Git history, source archives and review captures are not part of this package.
