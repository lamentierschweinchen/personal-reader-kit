# Beowulf

J. Lesslie Hall’s complete translation, from Project Gutenberg eBook 16328, with its front matter, source notes, marginal summaries and reference apparatus. **The world of the hall** is a separate illustrated historical companion: buildings, feasts, armor and making.

Run `npm test` and `npm run build`. This is an exact, separately reviewed public package, not the private development project. The original digital edition is pinned unchanged. Earlier companion data remains dormant in that immutable edition; the active experience is supplied by `site/hall-world.mjs`.
