# Gentium Plus

Reading, source quotations, commentary and serif headings use **Gentium Plus**, copyright 2003–2022 SIL International, under the **SIL Open Font License 1.1**. The sans cover and compact interface retain the system sans family. The four real faces provide regular, italic, bold and bold italic; source emphasis is not synthesized. The complete license ships as [GentiumPlus-OFL.txt](../site/GentiumPlus-OFL.txt).

The source is Google Fonts’ official `ofl/gentiumplus` directory at revision `47d54ca1ebb14fd864695f1d39dc734f39017c33`. Full upstream TTFs received WOFF2 compression only with fontTools 4.67.0 `woff2.compress`. Names, copyright and license tables, created/modified timestamps, cmaps, horizontal metrics and every glyph outline were independently compared with the upstream TTFs; no WOFF metadata, subsetting or design changes were introduced. See the [OFL compression exception](https://openfontlicense.org/ofl-faq/#2-2). All four actual cmaps were checked for the edition’s polytonic Greek. Local browser checks load all four faces using the Greek sample; visual reading, source-return, large print and actual-computed 200% checks remain separate from cmap coverage.
