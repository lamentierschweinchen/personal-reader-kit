# Dracula

Complete public reading edition with an optional short arcade game. Published at https://newreading.app/dracula/; the game is at /dracula/play/.

Run `npm test` and `npm run build`. The combined catalogue in ../../showcase mounts this explicit build with separate storage, cache and installation scopes. Book bytes are pinned; do not rewrite the edition. Source terms and full notices remain available in the reader. See [source and rights](docs/SOURCE-RIGHTS.md).

The independent preparation project and raw inputs remain outside this public repository. The owner authorized this reader and game for public release on 17 October 2026. This copy contains application code and the specifically reviewed edition only; no personal notes, browser records or preparation archives.
