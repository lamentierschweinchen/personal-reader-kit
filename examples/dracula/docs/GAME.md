# Castle escape

A short room escape inspired by Harker’s exploration of the locked castle in Chapters II–III. Take the key, use the dark alcoves, and return to the gate. The successful escape, floor plan, key placement and patrolling shadows are invented and identified as such in From the novel.

Every SVG room mark, character, key, gate and icon is newly authored. Paper, ink and oxblood colours follow the reader. No image services, fonts or copied illustration pixels are used. Original code and drawings use the example’s MIT license.

The only quotation is a contiguous exact excerpt from the pinned edition, chap03 / chap03-b030, credited to Jonathan Harker’s journal, Chapter III, 15 May. The optional source view links to [Project Gutenberg 345](https://www.gutenberg.org/ebooks/345). It requires no later plot knowledge. Full edition notices remain in the reader.

The game.json inventory pins every runtime file. No saved game progress, accounts or analytics. The return module preserves the reader route and registers the reader’s scoped offline copy; it does not modify reader records. Release checks cover keyboard and trusted touch completion, failure, replay, multi-touch release/cancel, rotation, pause and source views. Browser emulation is separate from physical-device and nonvisual acceptance.
