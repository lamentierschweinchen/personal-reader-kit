# War and Peace public example

This directory is the reviewed public copy of the independent War and Peace
reader. Read README.md, docs/SOURCE-RIGHTS.md and edition-lock.json before work.
Do not use a source checkout or private preparation folder as a deployment root.

Preserve the complete Maude novel and stable source/section/block identities.
Changes to its words, emphasis, notes, verse or whitespace need a separate source
review. Preserve the twelve image bytes, corrected captions, explicit picture
permissions and source-context return. Do not infer progress from a reference
visit. Keep required notices recoverable in Text & pictures and the first-use
notice remembered for the unchanged edition; do not interrupt every chapter.

The build takes only its named inputs and writes only dist/. Edition, font and
icon pins require evidence before updating. Private browser bundles, notes,
screenshots and test-results stay ignored. Never commit personal test records.

Use the kit's reader-copyeditor skill for changes to authored apparatus, then
run npm test, npm run build and the relevant browser checks. Publication remains
subject to the parent kit catalogue, input allowlists and public-history audit.
This example does not authorize publication of any other reader.
