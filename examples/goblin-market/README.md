# Goblin Market

Christina Rossetti’s complete title poem from the 1862 Macmillan first edition. Two engravings by Dante Gabriel Rossetti appear at the stanzas they illustrate. Focus hides the studies for continuous verse. Saved passages and reading place stay in this browser.

[Read the edition](https://newreading.app/goblin-market/) · [Sources, rights and reuse](docs/SOURCE-RIGHTS.md)

Run `npm test` and `npm run build` here with Node.js 22 or later. The exact build is in `dist/`. Serve it over a local HTTP origin or HTTPS so the service worker can cache the edition.
