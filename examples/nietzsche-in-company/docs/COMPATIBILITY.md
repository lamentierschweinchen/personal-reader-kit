# Editions and portable records

Both complete editions use `personal-reader/text@1`. The standard validation, anchor and bundle contracts are retained. All literary words, emphasis, source notes, separators and context notices are in the book objects. No external media adapter is needed.

Ordinary exact editions and records can be transferred with a private reading bundle. The optional comparison layout and its editorial observations are application features, not part of a portable book. Saved comparison notes carry both exact quoted passages and their source anchors. The 383-entry locator and source-note links are checked against the pinned editions during every build.

The accepted source books retain their IDs and source fingerprints. A bundle from the accepted reader that contains these exact books can restore its annotations and reading places here. Other imported books remain personal browser data; this application does not upload them. Conflicting editions with the same ID are refused rather than silently replacing anchors. Keep both original files and use the recovery export when a record needs repair.

Each origin has separate browser storage. The canonical catalogue mount also uses its own database and service-worker namespace. Neither a new domain nor a Home Screen installation promises automatic transfer of another browser's notes. Export, restore and check a private bundle before retiring an address. Browser storage can be cleared; offline caching is not a backup.

The build requires only the named public files. It does not read a sibling project, a source archive, `.reader/`, a private preview or a network source. The enclosing kit's exact deployment and publication inventories determine which files may leave the workspace.
