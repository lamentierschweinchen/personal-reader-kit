# Nietzsche in company

The complete 1910 English *Joyful Wisdom*, with Epicurus's complete *Letter to Menœceus* in C. D. Yonge's translation. Nietzsche's prelude, all 383 aphorisms, songs, prefaces and source notes remain available through Contents.

The companion places Nietzsche's two accounts of Epicurus—§45 and §370—beside the letter's reasons for choosing pleasures and pains. Open either passage in context without moving your main reading place. Saved passages, marginal notes and comparison notes stay in this browser until you export them.

This is the approved public snapshot of source revision `94a9f7fd661107ae41008c480d70618a9363d4c0`. Only the two featured books and their active comparison are packaged. Exact literary objects and their digital notices are preserved. The source's original circle-and-horizon artwork and device-font typography are unchanged. See [source rights and fidelity](docs/SOURCE-RIGHTS.md) and [compatibility](docs/COMPATIBILITY.md).

Run with Node 22 or newer; no application dependency installation is required:

```sh
npm test
npm run build
npm run dev
```

The standalone preview opens at `http://127.0.0.1:4495/`. `PORT` chooses another loopback port. The build reads only the exact pinned `edition/` inputs and named site assets, then produces `dist/`. Original sample writing is retained solely as a test fixture. No book downloads, private preparation directories or browser records are required to build.

`npm run test:browser` runs the focused Chromium/WebKit reading, annotation, context-return, portable-bundle and stopped-origin offline journeys. It needs Playwright and its browser engines available through `PLAYWRIGHT_MODULE`, `CHROME_PATH` and `WEBKIT_PATH` where applicable. Results belong in ignored `test-results/`.

The approved public mount is [newreading.app/nietzsche/](https://newreading.app/nietzsche/). The enclosing showcase scopes application URLs, storage, worker caches and installation identity to that route, preserving edition bytes. A new address starts with separate browser records; export a private reading bundle before moving, then restore and verify it at the new address.

The redistribution basis is US public-domain source editions, with their full Project Gutenberg notices retained. This is not a worldwide rights claim. The poetry contributor Paul V. Cohn's reported dates leave a specific UK term question in 2026, recorded in the source notes. Physical Home Screen installation, touch selection and screen-reader acceptance remain separate from browser automation.
