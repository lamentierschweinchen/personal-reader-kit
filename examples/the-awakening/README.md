# The Awakening

The complete novel by Kate Chopin, with a short reading of calling cards, visits and obligations in Chapter XVII, beside a page from M. E. W. Sherwood’s 1897 etiquette manual.

Owner-approved public edition at [newreading.app/awakening/](https://newreading.app/awakening/). Read [source and reuse details](docs/SOURCE-RIGHTS.md).

    npm test
    npm run build
    npm run dev

The finite build admits only its explicit runtime and edition files. The selected source checkpoint is `ba10530eb0edeb9479c33c5c0dc3f5cc4f76c7e2`. The prepared novel remains unchanged, including its metadata. The full source archives, private reviews and independent Git history are excluded. The page image is a separate offline application asset; a private reading bundle preserves text and records but does not package that image or the presentation code. Retain this application’s matching assets when moving the reader. Browser records are local to their origin; export a private bundle before changing addresses.

The kit’s `showcase/check-awakening.mjs` checks the actual mounted edition. Browser emulation does not establish physical-device acceptance.
