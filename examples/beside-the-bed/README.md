# Beside the Bed

Florence Nightingale’s complete Notes on Nursing, Appleton 1898, meets Walt Whitman’s complete Specimen Days. The visitor’s work follows preparations, messages, conversation and departure. Room for sound offers an optional close reading of a corridor and a singing ward; the notebook/publication evidence sits in a quieter Sources essay.

Canonical reader: [Beside the Bed](https://newreading.app/beside-the-bed/).
