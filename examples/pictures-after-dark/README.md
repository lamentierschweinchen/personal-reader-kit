# Pictures after dark

[Read the edition](https://newreading.app/pictures-after-dark/).

Eight complete works by Victor Hugo and Aloysius Bertrand, in French and historical English. Compare stanzas or paragraphs, inspect twelve illustrated pages, and read Bertrand’s open window beside Baudelaire’s closed one.

`npm test` checks the reader contracts and exact edition. `npm run build` verifies all selected inputs before producing `dist/`. `npm run dev` opens a loopback preview (default port4523). Reading records belong to that browser address; export a private reading bundle before moving.

The complete language editions, folio comparison and images are individually pinned in `edition-lock.json`. [Source and reuse terms](docs/SOURCE-RIGHTS.md) distinguish historical work, CC BY-SA community transcription, museum images and MIT software. This public package contains only the selected approved edition. It contains no private preparation or personal annotations.
