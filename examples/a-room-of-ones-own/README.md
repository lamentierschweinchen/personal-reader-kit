# A Room of One’s Own

Virginia Woolf’s 1929 Hogarth Press essay, with all six chapters and the original notes. The optional Chapter I note follows Newnham students’ response to the dinner scene.

Run `npm test` and `npm run build`. The builder verifies the complete reviewed package and its edition fingerprint before copying any assets. The built-in text is the pinned scan-backed Wikisource adaptation. Reading places and marginalia belong to the current browser.
