# Tea at Six

A 75-second tea-service arcade inspired by Chapter VII of Lewis Carroll’s Alice’s Adventures in Wonderland. Hold a cup to pour, release near the line, and refill between pours.

The owner approved the gameplay and requested a reader-aligned visual revision on 17 October 2026. The engine and input module remain byte-identical to that approved baseline: engine.mjs c6febf8b3f61a82eda5756b0b20c1110db854c4e9d9d17662c095f67c9a1c8b1; game.mjs 5d321b70de652493b4a916be2464cde6f16dc28f0855b1e2867428b2a3667fc3.

All SVG paths and game dialogue are newly authored adaptations. No Rackham image pixels or book excerpts are copied into the game. The reader’s paper, ink and blue palette guided the presentation. About credits the [source edition](https://www.gutenberg.org/ebooks/28885). No external fonts, images, analytics or accounts are used. Sound starts off and scores stay in memory. Code and original drawings use this example’s MIT license.

The game.json inventory pins every runtime file. Integration adds a reader return link and scoped offline caching without altering game rules or input. Reader notes, permissions and place remain in their own storage.
