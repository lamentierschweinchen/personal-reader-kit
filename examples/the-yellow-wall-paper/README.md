# The Yellow Wall-Paper

Read Charlotte Perkins Gilman’s complete story with Jo. H. Hatfield’s original engravings. **Original pages** opens the ten magazine pages. **The paper on the wall** looks at William Morris’s wallpaper and Rhoda and Agnes Garrett’s advice on decorating a sickroom.

Run `npm test` and `npm run build` with Node.js 22 or later, then serve `dist/`. New reading mounts this example at `/yellow-wall-paper/`. [Source and reuse](docs/SOURCE-RIGHTS.md)
