From a book to your own app

How it works.

An AI coding tool builds the reader with you. Describe what you want, try it, and ask for changes.

Set it up on a computer. Read on your phone.

  1. 01

    Open a workspace.

    Use a coding tool that can edit files and run a project. Codex and Claude Code both work.

    Set up CodexSet up Claude Code (paid plan)

    Create an empty folder called My reader and open it in your tool. This is where the reader’s files will live.

    Open your folder

    Codex: create a local project, use Add folder to select My reader, then open a Codex chat.

    Claude Code: open Code, choose Local, then Select folder and select My reader.

    The kit is free. Your chosen AI tool may have plan costs or usage limits.

  2. 02

    Give it this instruction.

    Get the kit

    Ask it to open the result. Read a page, highlight a sentence, save a note and reload. Your note should still be there.

  3. 03

    Make it yours.

    Add your book as plain text, or ask the tool to prepare an EPUB or PDF. Keep it simple, or make a companion around the book’s places, ideas or history.

    “Make the text larger on my phone. Keep the poem’s line breaks. Show me the result.”

    Try it as a reader. Ask for another version of anything that gets in the way.

    Book files given to an AI tool may be processed by its provider. Choose what you’re comfortable sharing.

  4. 04

    Take it with you.

    Ask your tool to publish the reader at your own web address. It can guide GitHub and Vercel setup when you need them.

    Open the site on your phone and add it to your home screen. Open that new icon while online. If your book or notes aren’t there, restore a reading bundle and check them in the app.

    In the app’s Settings, choose Check offline copy and wait for Available offline. Then turn off Wi-Fi and mobile data, reopen the reader and save a note. Keep a reading bundle as your backup.

A few useful answers.

What are GitHub, Node and Vercel?

GitHub can keep a versioned copy of your project. Node runs the reader while you build it. Vercel hosts the finished website. Let your tool guide the setup as each becomes useful; check any plan’s cost before choosing it.

Will any ebook work?

The reader imports plain text and prepared reader files. EPUBs and PDFs need preparation, and some layouts need extra work. DRM-protected ebooks cannot be imported by this kit. The included sample lets you try the process first.

What if I get stuck?

Tell the tool what you see: “I expected a preview, but I’m seeing an error. Find the cause and explain the next step.” If it only returns code, check that it can edit and run files in your project folder. Ask it to save a short progress note if you want to continue later.
