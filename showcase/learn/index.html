New to agents?

Your first reader.
Start here.

A coding agent can edit files and test a website for you. You describe what you want, try the result and ask for changes.

Use a computer for setup. You can read on your phone afterwards.

  1. 01

    Choose an agent.

    Starting from scratch? Try Codex in the ChatGPT desktop app. Claude’s Code tab is another option and requires a paid plan. Follow one of these official setup guides and sign in.

    Set up CodexSet up Claude Code

    Already have an agent? Use it if it can open a project folder, edit files and run commands. The kit is free; your agent’s plan may have costs or usage limits.

  2. 02

    Give it a folder.

    Create a folder on your computer called My reader. Your website’s files will live there.

    In Codex, create a local project and attach My reader using Add folder, then open a Codex chat. In Claude, open Code, choose Local, then Select folder and select My reader.

    The instruction below asks the agent to get the kit. If it needs help downloading or installing something, ask it to explain the next step in plain language.

  3. 03

    Try a first reader.

    View the kit

    Ask it to open a working preview. Read a page, highlight a sentence, save a note and reload. Check that the note is still there.

    Once that works, add a plain-text book, or ask the agent to prepare an EPUB or PDF.

    Files you give the agent may be sent to its provider. Share only what you’re allowed and comfortable to send.

    Choose a simple reader or try a companion built around its places, ideas or history. Be specific about what you want to change:

    “Make the text larger on my phone. Keep the poem’s line breaks. Show me the result.”
  4. 04

    Take it with you.

    Ask your agent to help publish the reader at your own web address. It can guide GitHub and Vercel setup when you reach that point.

    Open the finished site on your phone and add it to your home screen. Ask your agent to help move your book and notes using a private reading bundle. Check they arrived. Wait for “Available offline,” then turn off Wi-Fi and mobile data, reopen the reader and save a note.

A few things you might wonder.

What are GitHub, Node and Vercel?

GitHub can keep a versioned copy of your project. Node runs the reader while you build it. Vercel hosts the finished website. Let your agent guide the setup as each becomes useful; check any plan’s cost before choosing it.

Will any ebook work?

The reader imports plain text and prepared reader files. EPUBs and PDFs need preparation, and some formats need extra work to preserve their layout. DRM-protected ebooks cannot be imported by this kit. Start with the included sample to learn the process.

The agent is stuck—or only gives me code.

Tell it what you see: “I expected a preview, but I’m seeing an error. Find the cause and explain the next step.” If it cannot edit and run files, return to the coding workspace in step one. You can also ask it to save a short progress note so you can resume later.
