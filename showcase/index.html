Add a reader to your home screen

Open one of the readers above first.

iPhone & iPad
In Safari, open Share and choose Add to Home Screen. Enable Open as Web App if shown, then tap Add.
Android
In Chrome’s menu, choose Install and create shortcut, then Install. Some versions call this Add to Home screen or Install app.
Computer
In Chrome’s menu, choose Cast, save, and share, then Install page as app. On a Mac with Safari, choose File, then Add to Dock.

Open the new icon while online. In the reader’s Settings, choose Check offline copy, then try reopening it with Wi-Fi and mobile data off. If your books or notes aren’t there, restore a reading bundle from the browser where you saved them.
