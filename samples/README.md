# Original sample material

Both *The distance of a bell* and *A room after rain* were created with an AI assistant for this kit on 15 October 2026. They are fictional demonstration texts, not excerpts, imitations of a named author, public-domain transcriptions or scholarly sources. The author label is deliberately the project rather than an invented biographical persona.

The repository's MIT license grants reuse of the sample writing as well as the code. No claim of exclusive copyright in machine-generated material is necessary for this permission. No third-party full text, cover art, map or font is bundled.

Each sample's source hash covers its exact text plus inter-block separators in section order. The publication manifest separately hashes the complete JSON file. Update that hash only after manually reviewing all sample content and provenance. Never use the sample-hash approval path for a personal book.

The 17 October 2026 editorial pass revises the displayed About copy in the application's presentation layer. The complete sample JSON, including its original context, remains unchanged so previously exported full-book bundles stay compatible. The scoped display copy applies only to the built-in samples and does not modify edition objects or personal imports.
